# Audit Tool
Сервис для построения круговых и столбчатых диаграмм в рамках аудита IT-инфраструктуры заказчика.

## Установка сервиса
На выбор предлагается два варианта установки:
* на базе службы IIS Windows Server;
* в контейнере Docker.

Для установки и запуска сервиса необходимо выбрать релиз iis_v0.1 или Docker_v0.1 в зависимости от того, на базе чего будет развернут продукт. 

### Вариант установки на базе IIS Windows Server
1. Скачать релиз iis_v0.1.
2. Установить роль IIS на Windows Server (компонентов по умолчанию достаточно).
3. Создать папку в inetpub (например AuditTool), в нее распаковать вложить содержимое AuditProject. 
4. Открыть оснастку IIS.
5. Создать в DefaultApp новый веб-сайт.
6. Указать в качестве физического пути путь до папки AuditTool.
7. Настроить биндинг, хостнейм.
8. Настроить работу сервиса на защищенный протокол передачи данных https. 

### Вариант установки в контейнере Docker

1. Скачать релиз
```bash
wget https://github.com/LoySander/Audit_Project/archive/refs/tags/Docker_v0.1.tar.gz
```
2. Распаковать его
```bash
tar -xzf Docker_v0.1.tar.gz
```
3. Перейти в нужную директорию
```
cd Audit_Project-Docker_v0.1/Audit_Project/
```
4. Собрать образ контейнера
```
docker build -t audit-tool:0.1 .
```
5. Запустить контейнер
 ```
docker run -d --name audit-tool -p 80:80 --restart unless-stopped audit-tool:0.1
```
